# Ingeniería Metalúrgica · UTN FRC — Web de preinscripción

Sitio de promoción y preinscripción de la carrera de Ingeniería Metalúrgica (UTN Facultad Regional Córdoba).

- `index.html` — Web pública: trivia, información de la carrera, laboratorios, salida laboral, ingreso, preguntas frecuentes y formulario de preinscripción/consulta.
- `admin.html` — Panel de aspirantes (requiere email y clave del Departamento): tablero, seguimiento y cambio de condición Consultante → Ingresante → Estudiante.
- `assets/js/config.js` — URL de la planilla (Google Apps Script) y fecha de cierre de inscripciones.

Los datos se guardan en una planilla de Google; el código del servidor **no** está en este repositorio.
